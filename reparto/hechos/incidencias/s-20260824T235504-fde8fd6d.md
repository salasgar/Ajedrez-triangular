## Fallo real encontrado: `editor.html` no funciona sin conexión

Comprobación 7 (service worker), parte de navegador: `index.html` sí sigue
sirviéndose sin conexión, pero **`editor.html` NO** — se carga la página (HTML,
título y panel), pero el tablero se queda vacío, el selector de modalidad
queda sin opciones y la consola muestra 9 errores `Uncaught SyntaxError:
Unexpected token '<'` (uno por cada `<script>` de la página).

### Causa

`editor.html` carga sus nueve scripts con cadena de versión en la URL:

```
<script src="geometry.js?v=1"></script>
<script src="variants.js?v=1"></script>
<script src="rules.js?v=1"></script>
<script src="saveload.js?v=2"></script>
<script src="editor.js?v=3"></script>
<script src="ai.js?v=1"></script>
<script src="problemas.js?v=1"></script>
<script src="problema-imagen.js?v=1"></script>
<script src="crear-problema.js?v=1"></script>
```

pero `sw.js` cachea `FICHEROS` **sin** esa cadena de versión (`./geometry.js`,
`./rules.js`, etc.). `caches.match(request)` compara la URL entera, incluida
la query string, y por defecto no la ignora (`ignoreSearch` es `false`), así
que ninguno de los nueve ficheros hace hit en caché al pedirse con `?v=N`.
Sin red, el `fetch()` de reserva falla, y entonces entra el `.catch(() =>
caches.match('./index.html'))` del final del handler de `fetch` en `sw.js`:
ese catch-all está pensado para la navegación (mostrar algo en vez de nada),
pero también atrapa los `<script>` fallidos y les sirve el HTML de
`index.html` como si fuera el JS pedido — de ahí el `Unexpected token '<'`
(el navegador intenta parsear HTML como JavaScript).

`index.html` no tiene este problema porque sus propios `<script>` no llevan
cadena de versión.

### Cómo se comprobó

Playwright/Chromium headless, contexto con Service Worker permitido:
1. Cargar `index.html` online, esperar `navigator.serviceWorker.ready` y
   confirmar la caché `ajedrez-triangular-v7` con 22 ficheros.
2. `context.setOffline(true)`.
3. Navegar (carga de página real, no ruteo SPA) a `editor.html`: el HTML
   carga pero el tablero no se dibuja, la paleta queda vacía y hay 9
   `pageerror` de sintaxis. Captura:
   `reparto/salidas/08-verificacion/s-20260824T235504-fde8fd6d-07-offline-editor.png`.
4. Navegar a `index.html` en el mismo contexto offline: carga y funciona con
   normalidad (tablero completo, sin errores). Captura:
   `s-20260824T235504-fde8fd6d-07-offline-index.png`.
